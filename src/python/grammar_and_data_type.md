## 基本语法与数据类型

### 常见数据类型

#### 布尔类型

布尔类型由 ``True`` 和 ``False`` 组成。

#### 基本数据类型

基本数据类型包括整数类型 ( int ) 与实数类型 ( float )。

整数为 ``10`` ， ``20`` ， ``-2``这些无小数部分的数。

实数为 ``1.0`` ， ``3.14e-10`` ， ``4E5`` 这些带小数部分的数。

其中 e 和 E 都是科学计数法的表示方式。虽然 ``4E5`` 是数学意义上的整数，但在 Python 中，由于输出结果为 ``400000.0``， ``4E5`` 仍然被视作实数

由于 Python 存储数据的方式，实数存储数据并不精确，比如输入
````python
0.1+0.2
````
结果并不为 ``0.3``

#### 复合类型

复合类型包括列表、元组、集合等

集合也称容器，与数学意义上的集合基本一致，一般用来去重。

列表是用来记录一组有序数据项的集合，用[ ]开头和结尾，元素间用逗号隔开，如`` [1,2,3] ``

元组也是用来记录一组有序数据项的集合，与列表类似，但是其中的元素不可更改

集合是由一系列“键－值”对组成的集合，形如`` {key1:value1, key2:value2, …} ``，一般用于传参

#### 数据类型的判断

所有的数据都可以用`` type ``函数判断类型

如
````python
type(1)
````

输出结果为 int 

````python
type([1,2,3])
````

结果为 list

### 基本语法

#### 基本运算

| 运算符 | 功能 | 运算对象 | 运算结果 | 举例 |
| :---: | :---: | :---: | :---: | :--- |
| `+` | 加法 | 整数<br>实数 | 整数<br>实数 | `3 + 2 = 5`<br>`3.5 + 2.6 = 6.1` |
| `-` | 减法 | 整数<br>实数 | 整数<br>实数 | `3 - 2 = 1`<br>`3.6 - 2.5 = 1.1` |
| `*` | 乘法 | 整数<br>实数 | 整数<br>实数 | `3 * 2 = 6`<br>`3.6 * 2.5 = 9.0` |
| `**` | 乘方 | 整数<br>实数 | 整数<br>实数 | `3 ** 2 = 9`<br>`2.5 ** 2.0 = 6.25` |
| `/` | 除法 | 整数<br>实数 | **实数** | `5 / 2 = 2.5`<br>`12.5 / 2.5 = 5.0` |
| `//` | 取整除法 | 整数<br>实数 | 整数<br>实数 | `5 // 3 = 1`<br>`-5.6 // 2.0 = -3.0` |
| `%` | 求余 | 整数<br>实数 | 整数<br>实数 | `12 % 7 = 5`<br>`3.6 % 2.5 = 1.1` |

#### 变量

Python 没有"声明变量"这一步，直接赋值即可

- age = 18
- height = 1.75 
- name = "小明"
- is_student = True   

变量的命名规则


1. 只能由字母、数字、下划线组成，不能以数字开头；
2. 区分大小写，Age 和 age 是两个变量，一般用小写表变量，大写表常量；
3. 不能用关键字：if、for、class、def、True、None 等。

#### 输入与输出

输出所用的函数为`` print ``,例如

````python
print("Hello world")
````

如果需要一次输出多个结果，在中间加`` , ``即可

如：
````python
print(1,2,3)
````

Python中可以直接用" = "赋值。如

````python
a = 3
````

此时若 print(a), 结果为 3

````python
a = 3
print(a)
````

也可以用变量给另一个变量赋值，如：

````python
a = 3
b = a
print(b)
````

此时已经把 a 的值赋给 b ，故输出为 3.

在 Python 中，可以用`` n = n + 1 ``来实现 n 数值加一，也可以简写成`` n += 1 ``

````python
n = 0
n += 1
print(n)
````

此时输出结果为1

输入所用函数为 `` input `` ,格式为

````python
input ("请输入文本")
````

输入代码后屏幕上会显示“请输入文本”，此时可以在后面输入一个字符串，用回车结束。可以将该字符串与某个变量绑定，如果需要输入整数、实数等数据类型，可以使用强制类型转换

例如：
````python
a = input("请输入一个数字：")
print(a)
````

但是此时输入的1并不是整数，而是一个字符串，无法进行数学运算

````python
a = input("请输入第一个数字：")
b = input("请输入第二个数字：")
print(a + b)
````

此时的结果并不是3，而是12，如要进行数学运算，则需要将字符串转换为整数(`` int ``)或浮点数(`` float ``)

````python
a = int(input("请输入第一个数字："))
b = int(input("请输入第二个数字："))
print(a + b) 
````

掌握上述内容后就可以编写基础的代码了，如 BMI 的计算：
````python
height = int(input('请输入身高(cm)：'))
height = height / 100
weight = int(input('请输入体重(kg)：'))
bmi = weight / (height ** 2)
print("bmi:" , bmi)
````
