# 数据类型与基本语法

## 常见数据类型

### 布尔类型

布尔类型由 `True` 和 `False` 组成。

### 数字类型

数字类型包括整数类型 (`int`) 与浮点数类型 (`float`) 。

- **整数**如 `10` , `20` , `-2` 。
- **浮点数**如 `1.0` , `3.14e-10` , `4E5` 。

其中 e 和 E 都是科学计数法的表示方式。虽然 `4E5` 是数学意义上的整数，但在 Python 中，由于输出结果为 `400000.0`， `4E5` 仍然被视作浮点数。

由于 Python 存储数据的方式，浮点数存储数据并不精确，比如输入

```python
0.1 + 0.2
```

结果并不为 `0.3` 。

### 字符串类型

**字符串** (`str`) 用来记录文本，用一对单引号或双引号包裹，如 `'hello'` 、 `"小明"` 。单引号和双引号没有区别，但两端的引号必须一致。

如果字符串内部要出现同种引号或换行等特殊字符，可以改用另一种引号包裹，或使用转义字符：

```python
"It's ok"          # 外层是双引号，内部可以有单引号
'It\'s ok'         # \' 表示单引号本身
"第一行\n第二行"    # \n 表示换行
```

字符串可以用 `+` 拼接、用 `*` 重复、用 `len` 函数获取长度，也可以用 `in` 判断包含关系：

```python
"dep" + "sast"       # 'depsast'
"ab" * 3             # 'ababab'
len("hello")         # 5
"sast" in "depsast"  # True
```

与元组类似，字符串是不可变的，即创建之后不能单独修改其中某个字符，但可以通过**索引**和**切片**读取其中的一部分。索引从 `0` 开始，负数表示从后往前数；切片 `s[a:b]` 取出第 `a` 到第 `b - 1` 个字符，包含 `a` 但不包含 `b`。

```python
s = "depsast"
s[0]      # 'd'，第一个字符
s[-1]     # 't'，最后一个字符
s[0:3]    # 'dep'
```

字符串还自带一些常用方法 (即通过 `.` 调用的函数)，如

```python
"Hello".upper()      # 'HELLO'，转为大写
"Hello".lower()      # 'hello'，转为小写
"  hi  ".strip()     # 'hi'，去掉两端空白
"a,b,c".split(",")   # ['a', 'b', 'c']，按分隔符拆分成列表
```

字符串与数字之间可以用 `str`, `int`, `float` 相互转换。

#### 格式化字符串

在字符串前加 `f`，即可把变量或表达式写进花括号 `{}` 中，方便地生成文本，后续章节会大量使用：

```python
name = "小明"
age = 18
print(f"{name} 今年 {age} 岁")
print(f"明年 {age + 1} 岁")
```

### 复合类型

复合类型包括集合、列表、元组、字典等。

- **集合** (`set`) 与数学意义上的集合基本一致，其中的元素不重复且无序，一般用来去重；
- **列表** (`list`) 是用来记录一组有序数据项的集合，用 `[` `]` 开头和结尾，元素间用逗号隔开，如 `[1,2,3]` ；
- **元组** (`tuple`) 也是用来记录一组有序数据项的集合，与列表类似，但是其中的元素不可更改；
- **字典** (`dict`) 是由一系列“键－值”对组成的复合类型，形如 `{key1:value1, key2:value2, ...}`，可以通过键访问对应的值。

### 数据类型的判断

所有的数据都可以用 `type` 函数判断类型，如

```python
In [1]: type(1)
Out[1]: int

In [2]: type([1, 2, 3])
Out[2]: list
```

在 IPython 中，`type` 的结果会直接显示为 `int`、`list` 这样的简写；在普通脚本或交互式解释器中，显示的则是 `<class 'int'>`、`<class 'list'>`，两者含义相同。

## 基本语法

### 基本运算

| 运算符 | 功能 | 运算对象 | 运算结果 | 举例 |
| :---: | :---: | :---: | :---: | :--- |
| `+` | 加法 | 整数<br>浮点数 | 整数<br>浮点数 | `3 + 2 = 5`<br>`3.5 + 2.6 = 6.1` |
| `-` | 减法 | 整数<br>浮点数 | 整数<br>浮点数 | `3 - 2 = 1`<br>`3.6 - 2.5 = 1.1` |
| `*` | 乘法 | 整数<br>浮点数 | 整数<br>浮点数 | `3 * 2 = 6`<br>`3.6 * 2.5 = 9.0` |
| `**` | 乘方 | 整数<br>浮点数 | 整数<br>浮点数 | `3 ** 2 = 9`<br>`2.5 ** 2.0 = 6.25` |
| `/` | 除法 | 整数<br>浮点数 | **浮点数** | `5 / 2 = 2.5`<br>`12.5 / 2.5 = 5.0` |
| `//` | 取整除法 | 整数<br>浮点数 | 整数<br>浮点数 | `5 // 3 = 1`<br>`-5.6 // 2.0 = -3.0` |
| `%` | 求余 | 整数<br>浮点数 | 整数<br>浮点数 | `12 % 7 = 5`<br>`3.6 % 2.5 = 1.1` |

### 变量

Python 没有“声明变量”这一步，直接赋值即可，如：

- `age = 18`
- `height = 1.75`
- `name = "小明"`
- `is_student = True`

变量的命名规则：

1. 只能由字母、数字、下划线组成，不能以数字开头；
2. 区分大小写，`AGE` 和 `age` 是两个变量，一般用小写表示变量，全大写表示常量；
3. 不能用关键字：`if`, `for`, `class`, `def`, `True`, `None` 等。

### 输入与输出

#### `print` 输出与示例

输出所用的函数为 `print` ，例如

```python
print("Hello, world!")
```

如果需要一次输出多个结果，在中间加 `,` 即可，如

```python
print(1, 2, 3)
```

Python 中可以直接用 `=` 赋值，如

```python
a = 3
```

可以用 `print` 打印变量值

```python
a = 3
print(a)
```

也可以用变量给另一个变量赋值，如

```python
a = 3
b = a
print(b)
```

此时已经把 `a` 的值赋给 `b` ，故输出为 `3` 。

在 Python 中，可以用 `n = n + 1` 来实现 `n` 数值加一，也可以简写成 `n += 1`

```python
n = 0
n += 1
print(n)
```

此时输出结果为 `1` 。

#### `input` 输入与示例

输入所用函数为 `input` ，格式为

```python
input("请输入文本")
```

输入代码后屏幕上会显示`请输入文本`，此时可以在后面输入一个字符串，用回车结束。可以将该字符串与某个变量绑定，如果需要输入整数、浮点数等数据类型，可以使用强制类型转换

例如：
```python
a = input("请输入一个数字:")
print(a)
```

但是此时输入的 `1` 并不是整数，而是一个字符串，无法进行数学运算

```python
a = input("请输入第一个数字:")
b = input("请输入第二个数字:")
print(a + b)
```

此时的结果并不是 `3` ，而是 `12`，如要进行数学运算，则需要将字符串转换为整数 (`int`) 或浮点数 (`float`)

```python
a = int(input("请输入第一个数字:"))
b = int(input("请输入第二个数字:"))
print(a + b)
```

掌握上述内容后就可以编写基础的代码了，如 BMI 的计算：

```python
height = float(input('请输入身高 (cm):'))
height = height / 100
weight = float(input('请输入体重 (kg):'))
bmi = weight / (height ** 2)
print(f"bmi: {bmi:.2f}")
```
